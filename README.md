# Agricultural-Tractor Virtual-Prototype Studies: Published Papers and Minimal Source

This repository contains the latest public source snapshot for two published MDPI articles, their declared theoretical model inputs, experiment-generation code, figures and documentation. Frozen experiment outputs, trajectories, checkpoints, review correspondence and submission packages are excluded.

| Paper | Published article | Local PDF | Supplement |
| :---: | :---: | :---: | :---: |
| Paper 1 / Machines | [Machines 2026, 14(11), 1248](https://doi.org/10.3390/machines14111248) | [manuscript.pdf](manuscripts/paper1/manuscript.pdf) | [Supplement](manuscripts/paper1/supplementary.pdf) |
| Paper 2 / Energies | [Energies 2026, 19(21), 5024](https://doi.org/10.3390/en19215024) | [manuscript.pdf](manuscripts/paper2/manuscript.pdf) | [Supplement](manuscripts/paper2/supplementary.pdf) |

Paper 1: *Observer-Based Hybrid Position Holding for an Electrohydraulic Agricultural Hitch: A Two-Chamber Virtual-Prototype Stress Test*.

Paper 2: *Phase-Informed ECMS with Soft SOC Safeguarding for a Virtual Hybrid Agricultural Tractor*.

The two PDF files are the published versions supplied by the authors. The TeX files are clean public source snapshots derived from the latest proofread sources: publisher comments and proof-highlighting wrappers are removed, while the published scientific content is retained. The source PDFs generated by `build_manuscripts.sh` are local reproducibility builds; the checked-in PDFs remain the supplied published versions.

## Contents

| Path | Contents |
| :---: | :---: |
| `manuscripts/paper1/`, `manuscripts/paper2/` | Published PDFs, clean TeX sources, supplements, publisher classes and figures |
| `code/` | Hydraulic, observer, supply-extension, power-split and ECMS models |
| `tools/` | Minimal source-only runners and integrity verification |
| `parameters/` | Declared theoretical model parameter manifests |
| `manifests/` | Publication status and source mapping records |

Both articles study theoretical virtual prototypes. Their parameters and maps are declared model inputs; the papers do not claim vehicle, bench or target-component calibration. Numerical experiments do not establish hardware validation, global stability or universal performance.

The approximately 20% fuel-saving case in Paper 2 is a separate ideal, full-information diagnostic with a favorable map and relaxed terminal-SOC band. It is not the causal online result reported for the published primary protocol.

## Build and integrity check

```sh
python3 -m pip install -r requirements.txt
python3 tools/verify_release.py
./build_manuscripts.sh
```

Build in a separate clone or copy if the supplied published PDFs must be preserved. The build checks source compilation; it does not read or reproduce frozen published numerical outputs.

Main experiment runners write to an external workspace:

```sh
./reproduce_paper1.sh --workspace ../tractor-paper1
./reproduce_paper2.sh --workspace ../tractor-paper2
```

These are short source-level recomputation workflows. They create generated JSON only in the external workspace and do not read, download or include a private frozen-result archive.
