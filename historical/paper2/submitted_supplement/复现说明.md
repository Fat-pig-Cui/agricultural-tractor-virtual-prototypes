# 论文二补充材料复现说明

本补充包对应 Energies 投稿候选稿，研究对象是研究者定义的混合动力拖拉机虚拟平台，不包含目标机器实测或标定数据。

目录：

- `code/`：OS-ECVT、效率地图、电池、预测器、控制器和公共模块；
- `tools/`：V2 冻结留出、跨循环、地图/容量、MPC 负对照和理想上界脚本；
- `results/`：正文及诊断审计使用的冻结 JSON；
- `manifests/`：V2 参数与假设清单；
- `figures/`：相关冻结图件。

核心 V2 顺序：

```bash
python3 tools/run_paper2_viability_ecms_v2.py
python3 tools/run_paper2_v2_crosscycle_audit.py
python3 tools/run_paper2_v2_map_capacity_audit.py
python3 tools/plot_paper2_figures.py
```

正文 Figure 3 由 `tools/plot_paper2_controller_framework.py` 读取
`results/paper2_controller_framework_frozen_benchmark.json`。该文件是与正文 Table 2
一致的投稿冻结逐路径结果；未带 `frozen` 后缀的同名基准文件保留后续探索状态，
不作为本次投稿图的输入。Figure 5 由
`tools/plot_paper2_mpc_mechanism_map.py` 读取相应冻结机制图结果。

建议使用 Python 3.11 或更高版本。历史 MPC、动态规划和绘图脚本还需要 NumPy、SciPy 与 Matplotlib。冻结 JSON 已随包提供。接近 20% 的数值来自理想 full-information oracle，不属于严格因果控制器结果。
