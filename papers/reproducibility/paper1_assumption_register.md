# 论文一参数与假设登记册

版本：`paper1-v1.0`  
更新日期：2026-09-11  
适用正文：`MDPI_template_ACS/paper1_hitch_control_mdpi.tex`

## 使用规则

- 本登记册仅描述理论虚拟样机；不构成特定拖拉机、液压缸、阀或蓄能器的实测规格。
- `paper1_parameter_manifest.csv` 是全部 `LiftParameters` 字段的机器可读清单。`tools/export_paper1_traceability.py` 会逐项比对其中标称值与代码，并快照 `ExperimentConfig`、PID/SMC/DI-SMAC/压力代理和保持监督器的默认设置，生成带 SHA-256 指纹的 `results/paper1_traceability.json`。
- 来源类别的含义如下：`virtual_hydraulic_input` 和 `virtual_mechanical_input` 是研究者定义的虚拟部件输入；`reduced_order_coefficient` 是压差代理模型系数；`numerical_setting` 和 `measurement_setting` 是计算及噪声设置。当前版本没有将任何数值标记为特定硬件数据表值或实物标定值。
- `VP-1.0` 表示本文的虚拟样机定义版本。任何参数、算法或试验口径变更都必须递增版本，并重新导出清单、复跑对应实验和更新正文。

## 历史占位项处置

早期代码中存在 `valve_flow_m3_s`、`acc_pressure_gain` 和 `gravity_m_s2` 字段，但它们不参与论文一的状态更新或指标计算。为防止它们被误读为生效物理参数，`paper1-v1.0` 已删除这些字段。与实际状态方程有关的命令压差增益、模式速率、锁止损失保留量、温度增益和共模压力下限均已作为显式字段记录在 `LiftParameters` 及参数清单中。

## 复核命令

```bash
python3 tools/export_paper1_traceability.py --check
```

该命令应在完整实验复现之前和提交归档之前各执行一次。若清单与代码不匹配，命令以非零状态退出。
